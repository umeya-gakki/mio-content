# mio-content

学習アプリ「ミオと放課後クエスト」の教材データです。

- `content.json`：問題・解説・単元・アドバイス・ミオのセリフ・成長の物語・持ち物など
- アプリ本体と学習記録は、ここではなく別のサーバーにあります。このリポジトリには個人的な情報を置きません。

## 決まりごと
- 問題の `id` は一度付けたら変えない・再利用しない（学習記録が問題を id で覚えているため）。
- 使わなくなった問題は消さずに、単元から外すだけにする。
- 名前は `{name}` と書き、アプリ側で差し込む。
- 変更したら `version` を更新する。

## app.html（アプリ本体）
ミオと放課後クエストのアプリ本体です。サーバー（uvision.jp/mio-k7q3/）の index.html は入り口だけで、ここにある app.html を読み込んで動きます。
改良は app.html を直して push すれば、数分で届きます。push の前に、必ず手元で動作確認をすること。
